# Sound effect credits

The reaction sounds in this folder are real recordings used by the soundboard
(`src/lib/sounds.js`). Every file is **CC0 / public domain**, so it can be
redistributed and used commercially without attribution — the details are kept
here for traceability.

| File | Effect | Original recording | License |
|------|--------|--------------------|---------|
| `cheer.mp3` | 👏 Cheer | "Crowd Cheering" — https://freesound.org/s/365132/ | CC0 |
| `horn.mp3` | 📯 Horn | "Industrial Air Horn" — https://freesound.org/s/131930/ | CC0 |
| `wow.mp3` | 😮 Wow! | "Crowd Oooh.wav" — https://freesound.org/s/324890/ | CC0 |
| `applause.mp3` | 🎉 Applause | "Applause 1.WAV" — https://freesound.org/s/277022/ | CC0 |
| `laugh.mp3` | 😂 Laugh | "Crowd laugh.wav" — https://freesound.org/s/324894/ | CC0 |
| `whistle.mp3` | 🎶 Whistle | "whistle .wav" — https://freesound.org/s/151091/ | CC0 |

If any file is deleted or fails to load, `src/lib/sounds.js` automatically
falls back to its synthesized version of that effect, so the soundboard keeps
working.
